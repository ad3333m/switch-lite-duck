# Light Browser

Tiny Switch .nro that opens pages in the console's own web applet.

- A: open; X: Fit to screen (mobile layouts + auto-hiding footer, on by default); Y: bookmark last page; -: remove; +: exit
- Bookmarks: `sdmc:/switch/LightBrowser/bookmarks.txt` (one URL per line)
- Launch through a game (hold R) - the web applet won't open from the Album.

Built by GitHub Actions; grab `LightBrowser.nro` from the `latest` release.
